trolCommander
=============

Fork of muCommander file manager

See a full description at https://trolsoft.ru/en/soft/trolcommander/

How to build
============

Build jar file:
`gradlew clean build`

==============

Latest jar file: https://trolsoft.ru/content/soft/trolcommander/nightly/trolcommander.jar
